# AI News Digest

Ежедневный русскоязычный дайджест практических AI-новинок с отправкой в Telegram через GitHub Actions.

## Что отслеживается

- Бесплатные модели, бесплатные тарифы и API-квоты.
- Open-source модели и инструменты.
- Новые AI-ассистенты, агенты и приложения для массового использования.
- Растущие тренды и популярность моделей/приложений по публичным рейтингам OpenRouter.
- Важные релизы крупных AI-компаний.

Заголовки, описания и найденные фрагменты рейтингов автоматически переводятся на русский. Названия продуктов и моделей сохраняются в оригинале, где это возможно.

## Расписание

Ежедневно в 08:00 по Москве (05:00 UTC), также доступен ручной запуск через Actions.

## Setup

1. Создайте Telegram-бота через @BotFather и добавьте GitHub Secret `TELEGRAM_BOT_TOKEN`.
2. Напишите боту `/start`.
3. При первом запуске скрипт найдёт личный chat ID и сохранит его в GitHub Actions Variables как `TELEGRAM_CHAT_ID`. Для этого workflow использует стандартный `GITHUB_TOKEN` с правом `actions: write`.
4. Дальше chat ID берётся из Variables, повторно искать его не нужно.

Проект не использует платный LLM API. Перевод выполняется через публичный endpoint Google Translate; если переводчик временно недоступен, в сообщении может остаться оригинальный текст. Краткие описания основаны на аннотациях RSS, а не на полном прочтении каждой статьи.

Рейтинги OpenRouter отражают использование на самой платформе (например, токены или запросы), а не качество модели и не число уникальных пользователей.
