# AI News Digest

Репозиторий для публикации редакторского AI-дайджеста в Telegram.

## Архитектура

- ChatGPT выступает AI-редактором: ищет новости, читает первоисточники, проверяет факты и даты, оценивает важность и популярность, анализирует бесплатные условия и готовит выпуск на русском языке.
- Готовый выпуск сохраняется в `data/digest.json`.
- GitHub Actions запускается при изменении этого файла и только публикует уже подготовленный материал в Telegram.
- Python-скрипт не ищет новости, не ранжирует их и не переводит. Он только читает JSON, форматирует HTML и отправляет сообщения.

## Содержание дайджеста

Приоритет: бесплатные модели и тарифы, open-source/open-weights, новые AI-приложения и агенты, популярные инструменты и рейтинги (особенно OpenRouter), затем другие важные события AI-индустрии. GetCourse и EdTech исключены. В выпуске до 10 проверенных новостей; слабые пункты не добавляются ради количества.

## Формат data/digest.json

```json
{
  "date": "07.11.2026",
  "window": "За последние 24 часа",
  "news": [
    {
      "title": "Заголовок на русском",
      "text": "Редакторский анализ: что произошло, что умеет, кому полезно и почему важно.",
      "free_access": "Бесплатный тариф: подтверждённые условия и ограничения.",
      "popularity": "Показатель популярности, период и метод измерения.",
      "discussion": "Реакция сообщества, если подтверждена.",
      "links": [
        {"label": "Первоисточник", "url": "https://example.com"}
      ]
    }
  ],
  "takeaways": ["Вывод 1", "Вывод 2"]
}
```

Поля `free_access`, `popularity` и `discussion` необязательны. Ссылки должны вести на реальные первоисточники/обсуждения.

## Расписание и запуск

Редакторская задача ChatGPT работает ежедневно в 08:00 по Москве. После коммита `data/digest.json` workflow автоматически отправляет выпуск. Ручной запуск доступен в GitHub Actions через `workflow_dispatch`.

## Настройка

1. Добавьте GitHub Secret `TELEGRAM_BOT_TOKEN`.
2. Напишите Telegram-боту `/start`.
3. При первом запуске publisher определит личный chat ID и сохранит его в GitHub Actions Variables как `TELEGRAM_CHAT_ID`.
